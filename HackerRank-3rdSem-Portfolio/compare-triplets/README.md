## Problem: Compare the Triplets
**Link:** https://www.hackerrank.com/challenges/compare-the-triplets/problem

### Approach
Iterated through the 3-element rating arrays for Alice ($a$) and Bob ($b$). Used conditional comparisons (`>` and `<`) to increment respective scores when one rating strictly exceeds the other.

### Complexity
- **Time Complexity:** $O(1)$ — Executes exactly 3 iterations.
- **Space Complexity:** $O(1)$ — Returns a fixed-size 2-element list.
